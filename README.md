# ServiceLink Pro

ServiceLink Pro is a Flask and SQLite web application that connects clients with home service providers for services such as plumbing, HVAC, and cleaning.

---

## Features

- User Registration
- User Login and Logout
- Create Job Requests
- Assign Providers to Jobs
- Record Payments
- Submit Reviews
- Dynamic Dashboard Updates
- SQLite Database Integration
- Cloud Deployment with Render

---

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

## How to Run Locally

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/servicelink-pro-final.git
```

Navigate into the project folder:

```bash
cd servicelink-pro-final
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open in browser:

```plaintext
http://127.0.0.1:5000
```
