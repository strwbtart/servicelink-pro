# ServiceLink Pro

ServiceLink Pro is a Flask and SQLite web application for connecting clients with home service providers.

## Features
- User registration
- User login/logout
- Job request creation
- Provider assignment
- Payment recording
- Review submission
- Dashboard workflow tracking

## How to Run
1. Install Python
2. Install Flask:
   pip install flask
3. Run:
   python app.py
4. Open:
   http://127.0.0.1:5000
